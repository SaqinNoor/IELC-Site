- nelc1-1.jpg, nelc1-2.jpg, nelc1-3.jpg, nelc1-4.jpg, nelc1-5.jpg (1st Carnival)
- nelc2-1.jpg, nelc2-2.jpg, nelc2-3.jpg, nelc2-4.jpg, nelc2-5.jpg (2nd Carnival)
- nelc3-1.jpg, nelc3-2.jpg, nelc3-3.jpg, nelc3-4.jpg, nelc3-5.jpg (3rd Carnival)
- nelc4-1.jpg, nelc4-2.jpg, nelc4-3.jpg, nelc4-4.jpg, nelc4-5.jpg (4th Carnival)
- nelc5-1.jpg, nelc5-2.jpg, nelc5-3.jpg, nelc5-4.jpg, nelc5-5.jpg (5th Carnival)
- nelc6-1.jpg, nelc6-2.jpg, nelc6-3.jpg, nelc6-4.jpg, nelc6-5.jpg (6th Carnival)

### Eloquence Events
Place images in this format:
- eloquence1-1.jpg, eloquence1-2.jpg, eloquence1-3.jpg, eloquence1-4.jpg (Eloquence 1.0)
- eloquence2-1.jpg, eloquence2-2.jpg, eloquence2-3.jpg, eloquence2-4.jpg (Eloquence 2.0)
- eloquence3-1.jpg, eloquence3-2.jpg, eloquence3-3.jpg, eloquence3-4.jpg (Eloquence 3.0)

## Image Specifications
- Recommended aspect ratio: 16:9
- File formats: JPG, PNG
- Maximum file size: 2MB per image
- Resolution: 1920x1080 or higher recommended
